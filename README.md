# Donner un cerveau à l'IA de votre équipe

Source du site https://chronono.github.io/cerveau-ia/ : neuf fiches, leur résumé et les coulisses de leur écriture, par Olivier & Mentordinator.

Les pages de `content/` sont copiées du vault Obsidian d'Olivier par `python publier.py --pousser` ; on les corrige dans le vault, jamais ici. Chaque push sur `main` reconstruit le site avec [Quartz](https://quartz.jzhao.xyz) 4.5.2 (licence MIT, `LICENSE.txt`) et le publie sur GitHub Pages.
